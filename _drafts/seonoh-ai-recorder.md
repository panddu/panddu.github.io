기존에 AI 녹음기를 쓰면서 가장 크게 체감되던 진입장벽은 **기기값 외에 매달 나가는 'AI 구독료'**였습니다. 녹음 파일 저장까진 무료여도, 실제 필요한 화자 구분 전사나 요약 기능을 쓰려면 월 구독이 필수인 구조가 일반적이었기 때문입니다.

이번에 국내 기업인 **서앤오**에서 출시한 AI 캡슐 녹음기를 몇 주간 써보게 되었는데, 개발자/헤비유저 입장에서 눈에 띄는 차별점들이 있어 간단히 정리해 봅니다.

---

### 눈여겨볼 핵심 포인트

#### 1. AI 기능에 별도 구독료가 없다
보통 이런 기기들은 외부 상용 LLM API(OpenAI 등)를 호출하는 구조라 월 과금이 불가피합니다. 그런데 서앤오는 **자체 수급 GPU로 국내에 추론 API 서버를 직접 구축**했다고 합니다.  
덕분에 캡슐 기기값 외에는 전사, 화자 구분, 요약, 마인드맵 분석, 전사 내용 기반 질의응답까지 **추가 과금 없이 무료**로 사용할 수 있습니다.

#### 2. ChatGPT·Claude 플러그인은 물론 MCP(Model Context Protocol) 지원
전용 앱에만 갇혀 있으면 결국 복사-붙여넣기의 반복이 됩니다. 서앤오는 ChatGPT와 Claude 플러그인을 기본 제공하고, 더 나아가 **Claude Code나 에이전트 도구에서 쓸 수 있는 MCP 커넥터**를 제공합니다.  
회의나 인터뷰 녹음본을 AI 코딩 에이전트의 컨텍스트로 바로 연결할 수 있다는 점은 개발자 관점에서 꽤 매력적인 포인트였습니다. (Zapier, Notion, Slack 연동도 지원합니다.)

#### 3. 국내 서버 & 데이터 보안
계정당 5GB의 클라우드 공간이 제공되며, 스토리지뿐만 아니라 자체 LLM 서버까지 모두 **국내에 서버를 구축**해 데이터 해외 반출 우려가 없습니다. 사내 회의록 보안에 민감한 분들에게는 유의미한 부분입니다.

#### 4. K-기업의 광기 어린 피드백 반영 속도
초기 사용 시 앱 동선이나 동기화 방식 등에서 몇 가지 아쉬운 점이 있었습니다. 영상 초안을 정리해 주말 일요일 밤 10시쯤 전달드렸는데, 30분 만에 회신을 주시더니 **다음 날 오전에 바로 앱 수정 배포**를 완료해 주셨습니다. 제품을 진심으로 빠르게 개선하고 있다는 인상을 강하게 받았습니다.
